# 🚀 اضافه کردن داکیومنت Framework

این prompt برای اضافه کردن داکیومنت endpoint جدید به Framework Package استفاده می‌شه.

## 📋 دستورالعمل کلی

```
من می‌خوام یک endpoint جدید به framework package اضافه کنم و داکیومنتش رو کامل بنویسم. لطفا مراحل زیر رو به ترتیب انجام بده:

1. **تحلیل endpoint**: endpoint رو بررسی کن و مشخصاتش رو تعیین کن
2. **افزودن به API_ENDPOINTS**: endpoint رو به api-endpoints.ts اضافه کن
3. **ایجاد Route Structure**: فولدر و فایل‌های مورد نیاز رو بساز
4. **تعریف Types**: تمام interfaceها و typeهای مربوط به endpoint رو تعریف کن
5. **ایجاد توابع API**: توابع GET، POST، PUT، DELETE رو بساز
6. **ایجاد React Query Hooks**: هوک‌های مربوط به endpoint رو بساز
7. **Export و Build**: endpoint رو export کن و build کن
8. **ایجاد داکیومنت کامل**: فایل MDX داکیومنت‌اسیون رو بساز
9. **آپدیت سایر فایل‌های داکیومنت**: meta.json، index.mdx و سایر فایل‌ها رو آپدیت کن
10. **ایجاد CHANGELOG**: تغییرات رو در CHANGELOG ثبت کن
```

### مرحله 3: ایجاد GET Functions

```typescript
// packages/framework/src/routes/[endpoint-name]/get.ts

import type { I[EndpointName]Item, Get[EndpointName]ListParams } from "./type";
import type { APIHttpPaginatedType } from "../../types";
import API_ENDPOINTS from "../../utils/api-endpoints";
import APIHttp from "../../utils/api-http";

// ============================================================================
// CONSTANTS
// ============================================================================

const DEFAULT_PAGE_NO = 1;
const DEFAULT_ROW_COUNT = 10;

// ============================================================================
// FUNCTIONS
// ============================================================================

export function Get[EndpointName]List(
  params?: Get[EndpointName]ListParams,
): Promise<APIHttpPaginatedType<I[EndpointName]Item>> {
  const { pageNo = DEFAULT_PAGE_NO, rowCount = DEFAULT_ROW_COUNT, search } = params || {};
  
  return APIHttp.get(API_ENDPOINTS.[ENDPOINT_NAME].LIST, {
    params: {
      pageNo,
      rowCount,
      ...(search ? { search } : {}),
    },
  });
}

export function Get[EndpointName]Detail(id: string): Promise<{ data: any }> {
  return APIHttp.get(`${API_ENDPOINTS.[ENDPOINT_NAME].DETAIL}/${id}`);
}
```

### مرحله 4: ایجاد POST Functions

```typescript
// packages/framework/src/routes/[endpoint-name]/post.ts

import APIHttp from "../../utils/api-http";
import API_ENDPOINTS from "../../utils/api-endpoints";
import { ICreate[EndpointName]Request, IUpdate[EndpointName]Request } from "./type";
import { APIHttpType } from "../../types";

export function Create[EndpointName](
  data: ICreate[EndpointName]Request
): Promise<APIHttpType<any>> {
  return APIHttp.post(API_ENDPOINTS.[ENDPOINT_NAME].CREATE, data);
}

export function Update[EndpointName](
  data: IUpdate[EndpointName]Request
): Promise<APIHttpType<any>> {
  const { id, ...updateData } = data;
  return APIHttp.put(`${API_ENDPOINTS.[ENDPOINT_NAME].UPDATE}/${id}`, updateData);
}
```

### مرحله 5: ایجاد React Query Hooks

```typescript
// packages/framework/src/routes/[endpoint-name]/query.ts

import { useGenericQuery } from "../../utils/generic-query";
import { useGenericMutation } from "../../utils/generic-mutation";

import {
  Get[EndpointName]List,
  Get[EndpointName]Detail,
} from "./get";

import {
  Create[EndpointName],
  Update[EndpointName],
} from "./post";

import type { Get[EndpointName]ListParams } from "./type";

// ============================================================================
// QUERIES
// ============================================================================

export const use[EndpointName]ListQuery = (params?: Get[EndpointName]ListParams) =>
  useGenericQuery(
    () => Get[EndpointName]List(params),
    [
      "get-[endpoint-name]-list",
      String(params?.pageNo ?? 1),
      String(params?.rowCount ?? 10),
      String(params?.search ?? "")
    ]
  );

export const use[EndpointName]DetailQuery = (id: string) =>
  useGenericQuery(
    () => Get[EndpointName]Detail(id),
    ["get-[endpoint-name]-detail", id],
    { enabled: Boolean(id) }
  );

// ============================================================================
// MUTATIONS
// ============================================================================

export const useCreate[EndpointName]Mutation = () =>
  useGenericMutation(Create[EndpointName], ["get-[endpoint-name]-list"]);

export const useUpdate[EndpointName]Mutation = () =>
  useGenericMutation(Update[EndpointName], ["get-[endpoint-name]-list", "get-[endpoint-name]-detail"]);
```

## 📝 قوانین مهم

### 1. **Naming Conventions**
- Folder: `kebab-case` (article, user-profile)
- Files: `kebab-case` (type.ts, get.ts, post.ts)
- Interfaces: `PascalCase` با prefix `I` (IArticle, ICreateArticleRequest)
- Functions: `PascalCase` (GetArticleList, CreateArticle)
- Hooks: `camelCase` با prefix `use` (useArticleListQuery, useCreateArticleMutation)

### 2. **File Organization**
```
routes/[endpoint-name]/
├── type.ts      # تمام interfaces و types
├── get.ts       # فقط توابع GET
├── post.ts      # توابع POST و PUT برای create/update
├── update.ts    # توابع PUT خاص (optional)
├── delete.ts    # توابع DELETE (optional)
├── query.ts     # فقط React Query hooks
└── index.ts     # Export همه چیز
```

### 3. **Documentation Structure**
هر داکیومنت endpoint باید شامل این بخش‌ها باشه:
1. **Overview** - معرفی و ویژگی‌ها
2. **API Endpoints** - لیست کامل endpoints
3. **File Structure** - ساختار فایل‌ها
4. **Types & Interfaces** - همه interfaces با مثال
5. **GET Functions** - توابع GET با مثال
6. **POST/PUT Functions** - توابع POST/PUT با مثال
7. **React Query Hooks** - hooks با مثال
8. **Complete Example** - یک مثال کامل
9. **Best Practices** - نکات مهم
10. **Common Issues** - مشکلات رایج
11. **Available Hooks Table** - جدول خلاصه

### 4. **Code Examples**
- همه مثال‌ها باید کامل و قابل اجرا باشند
- از syntax highlighting استفاده کن
- مثال‌های واقعی و کاربردی بنویس
- شامل error handling و loading states

### 5. **Query Keys Convention**
```typescript
// Format: ["action-resource-detail", ...params]
["get-article-list", String(pageNo), String(rowCount), String(search)]
["get-article-detail", articleId]
["create-article"]
```

### 6. **Documentation Links**
- همیشه لینک به بخش‌های مرتبط بده
- از relative paths استفاده کن
- لینک‌های Examples، API Reference، Usage Guide
