# Authentication System Documentation

## 📖 Overview

The digi-framework uses a secure, two-step OTP (One-Time Password) authentication system for user login. This system provides a seamless and secure authentication experience with phone number verification.

## 🚀 Quick Start

### 1. Basic Implementation

```typescript
import { OTPLoginForm } from "@workspace/custom-ui";
import { useRouter } from "next/navigation";

export default function LoginPage() {
  const router = useRouter();

  return (
    <OTPLoginForm
      onSuccess={() => router.push('/dashboard')}
      onError={(error) => console.error(error)}
    />
  );
}
```

### 2. Wrap Your App with Provider

```typescript
import { CustomUIProvider } from "@workspace/custom-ui";

export default function RootLayout({ children }) {
  return (
    <CustomUIProvider 
      loginRoute="/auth" 
      appRoute="/dashboard"
    >
      {children}
    </CustomUIProvider>
  );
}
```

### 3. Protect Your Routes

```typescript
import { AuthGuard } from "@workspace/custom-ui";

export default function ProtectedPage() {
  return (
    <AuthGuard>
      <YourContent />
    </AuthGuard>
  );
}
```

## 🔑 Key Features

- ✅ **Two-Step Verification** - Phone number + OTP code
- ✅ **Secure Token Management** - HTTP-only cookies
- ✅ **Auto-logout** - Automatic logout on token expiry
- ✅ **User Profile Fetching** - Automatic profile loading after login
- ✅ **Modern UI** - Beautiful, responsive login form
- ✅ **Error Handling** - Comprehensive error management
- ✅ **Form Validation** - Client-side validation for better UX
- ✅ **Resend OTP** - Built-in OTP resend with cooldown timer

## 🎯 Authentication Flow

```
User enters phone → OTP sent → User enters OTP → Token saved → Profile fetched → Redirect to dashboard
```

## 📝 Usage in Your App

### Get Authentication State

```typescript
import { useAuthContext } from "@workspace/custom-ui";

function MyComponent() {
  const { 
    user,              // Current user
    isAuthenticated,   // Auth status
    loading,           // Loading state
    logout             // Logout function
  } = useAuthContext();

  return (
    <div>
      {isAuthenticated ? (
        <p>Welcome, {user?.name}</p>
      ) : (
        <p>Please login</p>
      )}
    </div>
  );
}
```

### Manual Login

```typescript
import { useAuthContext } from "@workspace/custom-ui";

function LoginComponent() {
  const { loginWithToken, verifyOTP } = useAuthContext();

  const handleLogin = async () => {
    // Step 1: Send OTP
    await loginWithToken({ 
      username: "09123456789", 
      password: "0" 
    });

    // Step 2: Verify OTP
    await verifyOTP({ 
      userPhone: "09123456789", 
      userOTP: "123456" 
    });
  };

  return <button onClick={handleLogin}>Login</button>;
}
```

## 🐛 Troubleshooting

### Common Issues:

1. **Token not persisting** - Check cookie configuration
2. **401 errors** - Verify token format (`Token ${token}`)
3. **OTP not received** - Check backend endpoint and phone format
4. **Redirect loop** - Ensure `loginRoute` and `appRoute` are different

See the [complete guide](./login-system-prompt.md) for detailed troubleshooting.
